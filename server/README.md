# Optional Backend (Express + MongoDB)

This folder is optional and not required for the Next.js frontend to run.

## Features

- Contact form API (store messages)
- Projects API (CRUD)
- Admin login (JWT)

## Setup

```bash
cd server
npm.cmd install
copy .env.example .env
npm.cmd run dev
```

## Notes

- This is a lightweight scaffold for local development and demos.
- For production, add proper rate-limiting, validation, and a real admin user management workflow.
