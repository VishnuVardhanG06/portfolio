# Branding System

## 1) Bio (first-person)

I’m Vishnu Vardhan, a Data Science undergraduate building machine learning and computer vision projects with a strong interest in geospatial intelligence. I like work that starts with messy real-world data and ends with something useful: a reproducible pipeline, a clear evaluation story, and an interface that makes results easy to understand. I’m currently seeking research opportunities where I can contribute to ML, CV, and remote sensing problems with solid fundamentals and end-to-end ownership.

## 2) Taglines (5 options)

1. Machine Learning, Computer Vision, and Geospatial Analytics
2. Data Science undergrad building research-ready ML systems
3. Turning messy data into reliable ML and geospatial insights
4. ML + CV + Remote Sensing projects with real-world constraints
5. Practical AI engineering for vision and satellite data

## 5) Favicon concept

Rounded square with a strong diagonal gradient (Ink -> Cobalt), using a single bold initial "V" as the mark. Implemented at `public/favicon.svg`.

## 6) UI style

Modern minimal with a light "glass" layer, crisp typography, and research/engineering vibes (grid texture + soft color glows).

## 7) Icon style

Line icons, consistent stroke weight, minimal fills (Lucide set).

## 8) Background style

Subtle dotted grid + large blurred color fields. Uses warm/cool contrast so the site feels energetic without looking loud.
